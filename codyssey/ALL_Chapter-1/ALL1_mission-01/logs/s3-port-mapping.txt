# 관찰:
#  - 실험 1(-p 없음, my-web-nomap): curl localhost:8080 → "Failed to connect" (연결 실패). docker ps PORTS 칸은 "80/tcp"(컨테이너 안에서만 열림)

#  - COPY로 nginx 기본 페이지 자리에 site/index.html 을 넣었기 때문에 기본 안내 페이지 대신 내 페이지가 서빙됨.
