# S4-1. 바인드 마운트 반영 확인 (2026-11-05, 사용자 실행 원본, Ubuntu / bash / WSL2 + Docker Desktop 4.78.0)
# 구성: my-web-bind(8081, -v 로 내 site/ 폴더를 /usr/share/nginx/html 에 마운트) vs my-web-8080(COPY로 구운 이미지)
# 관찰:
#  - 8081 변경 전 "Hello from my custom nginx container!" → site/index.html 수정·저장 후 "Bind mount works" (재시작/재빌드 없이 즉시 반영)
#  - 8080 은 수정 후에도 "Hello from my custom nginx container!" 그대로 (빌드 때 COPY한 사본)
#  - docker inspect: bind <내 PC의 site 폴더> -> /usr/share/nginx/html  (바인드 마운트 연결을 Docker가 직접 확인)
# 참고: 컨테이너를 만든 docker run -d -p 8081:80 --name my-web-bind -v "$(pwd)/site":/usr/share/nginx/html my-web:1.0 명령 줄은
#       이 터미널 출력에 포함되지 않았고, 대신 docker ps(8081 포트, 이름 my-web-bind) + docker inspect(마운트 경로)로 같은 구성이 확인됨.
#       첫 시도 기록(변경 후만 있음)은 logs/s4-bind-mount-partial.txt 에 보존.
# 참고: 이 출력의 curl 은 -s / grep 없이 전체 HTML 출력.
