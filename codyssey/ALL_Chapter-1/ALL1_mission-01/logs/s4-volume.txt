# S4-2. Docker 볼륨 영속성 검증 (2026-11-05, 사용자 실행 원본, Ubuntu / bash / WSL2 + Docker Desktop 4.78.0)
# 구성: 볼륨 mydata 를 컨테이너의 /data 에 연결. 같은 컨테이너 안에서 /data/hello.txt(볼륨) 와 /tmp/lost.txt(볼륨 아님) 두 파일을 생성.
# 관찰: 컨테이너(vol-test) 삭제 후, 같은 볼륨을 연결한 새 컨테이너(vol-test2)에서
#   - /data/hello.txt → 내용 "hi" 가 그대로 남아 있음 (볼륨에 저장된 데이터는 컨테이너 삭제 후에도 유지)
#   - /tmp/lost.txt   → "No such file or directory" (볼륨 밖 데이터는 컨테이너와 함께 사라짐)
# (사용자는 실행 전 남는다/사라진다 예측을 파일별로 따로 적지 않고 출력만 공유함)
# 참고: docker ps -a 출력에서 vol-test 는 삭제되어 목록에 없음(삭제 후 확인). 다른 컨테이너 줄은 앞 실습의 잔존 컨테이너.
