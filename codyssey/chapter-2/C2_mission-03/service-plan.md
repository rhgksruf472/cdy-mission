# 서비스 기획서 — 루틴프렌드 (RoutineFriend)

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 루틴프렌드 (RoutineFriend) |
| 목적 | 헬스장 등록이 부담스러운 홈트 초보자에게, 목표·경험·가용 시간에 맞는 운동 루틴을 AI가 즉석에서 짜준다 |
| 타겟 사용자 | 운동 경험이 적은 2030 직장인/학생, 집에서 짧게라도 운동을 시작하고 싶은 사람 |
| AI API | Anthropic Claude API |

## 2. 페이지 구성 (메뉴 이동 가능, 4개)

| 페이지 | 역할 |
|---|---|
| 메인(Hero) | 서비스 소개 + "루틴 추천받기" 버튼(AI 추천 페이지로 이동) |
| AI 루틴 추천 (핵심 기능) | 입력 폼 제출 → Claude 호출 → 맞춤 운동 루틴 결과 표시 |
| 운동 백과 | 기본 운동 목록/설명 (정적 콘텐츠 페이지) |
| 소개/문의 | 서비스 소개, 문의 폼 |

## 3. AI 기능 설계

- **입력**
  - 목표: 체중감량 / 근력 / 유연성 / 자세교정 (택 1)
  - 운동 경험: 초급 / 중급 / 고급 (택 1)
  - 부상·제약 부위: 선택 입력(텍스트 또는 체크박스)
  - 하루 가용 시간: 15 / 30 / 45 / 60분 (택 1)
- **출력**
  - 운동 목록: 운동명, 세트/횟수 또는 시간, 순서
  - 예상 소요시간
  - 주의사항 및 대체 운동 제안
- **사용자에게 제공할 가치**: 헬스 지식이 없어도 "지금 내 상황에 맞는" 운동 계획을 바로 받아볼 수 있다.
- **실패 처리 기준**
  | 상황 | 처리 |
  |---|---|
  | 빈 입력(목표/시간 누락) | 폼 제출 막고 "목표와 가능 시간을 선택해주세요" 안내 |
  | API 오류(4xx/5xx) | "일시적인 오류입니다. 잠시 후 다시 시도해주세요" 안내 |
  | 응답 지연/타임아웃 | 로딩 상태 표시 + 일정 시간 초과 시 안내 메시지 |
