# 서울 일별 기온 시계열 분석 리포트

## 1. 분석 주제 및 선정 이유

- 2026년 여름 유난히 더웠던 경험과, 뉴스에서 매년 역대 폭염 기록이 갱신된다는 보도를 접하며
  실제 데이터로도 이 흐름이 확인되는지 궁금해졌다.

## 2. 분석 질문

1. 서울 연평균 기온은 지난 10년간 상승 추세인가? 상승했다면 몇 ℃인가?
2. 여름과 겨울 중 어느 쪽이 더 빠르게 더워지고 있는가?
3. 일최고기온 33℃ 이상 폭염일이 매년 늘고 있는가?

세 질문은 각각 평균의 흐름(Q1), 계절별로 쪼갠 모습(Q2), 평균에 가려지는 극단값(Q3)이라는
서로 다른 각도로 골랐다.

## 3. 데이터 설명

- 출처: Open-Meteo Historical Weather API (ERA5 재분석 자료, API 키 불필요)
- 위치: 서울 (위도 37.5665, 경도 126.9780)
- 기간: 2016-01-01 ~ 2025-12-31 (10년, 3,653일)
- 컬럼: date(날짜), temp_mean(일평균기온), temp_max(일최고기온), temp_min(일최저기온)
- 결측치: 0건, 날짜 누락: 0건, 논리 오류(최저>최고): 0건
  (원본이 관측소 실측이 아닌 재분석 자료라 구조적으로 결측이 거의 없음)

## 4. 분석 결과 및 시각화

### Q1. 서울 연평균 기온 추세
![연평균 기온 추세](images/01_yearly_trend.png)

- 적용 기법: 연도별 집계, 365일 이동평균, 구간별(3개년) 평균 비교
- 2016~2025 끝점만 비교하면 +0.36℃지만, 2016~2018 평균(11.63℃) 대비
  2023~2025 평균(12.59℃)은 +0.97℃ — 끝점 비교가 시작 연도(2016년, 이례적으로 따뜻)에
  좌우되어 실제 상승폭을 과소평가함

### Q2. 여름 vs 겨울 기온 변화
![여름·겨울 기온 추이](images/02_summer_winter.png)

- 적용 기법: 계절별(월 기준) 재분류 — 겨울은 12월을 다음 해로 재배정, 계절별 구간 평균 비교
- 여름 변화(2016~18→2023~25): +0.76℃ / 겨울 변화(2017~19→2023~25): +0.58℃
- ※ 겨울 비교는 2017년부터 시작 — 2016년(1·2월만 존재)과 2026년(12월만 존재)은
  월 구성이 불완전해 제외함

### Q3. 폭염일수 추이
![폭염일수 추이](images/03_heatwave_days.png)

- 적용 기법: 조건부 카운트(temp_max≥33℃), 평균·중앙값 교차검증
- 연도별 폭염일수: 2016=2, 2017=1, 2018=18, 2019=8, 2020=1, 2021=8, 2022=2, 2023=4, 2024=5, 2025=22
- 평균 기준 변화 +3.3일, 중앙값 기준 변화 +3.0일 — 두 통계치가 일치해 2018·2025 두 해의
  우연한 극단값 때문만은 아니라고 판단함

## 5. 인사이트

**인사이트 1 (추세)**
- 관찰: 2016~2022년은 W자 모양으로 오르내리다가(2018·2022 저점), 2022→2024년 뚜렷하게
  상승(11.37℃→12.88℃), 2025년은 소폭(-0.15℃) 하락했다.
- 해석: 온난화 가설과 일치하나 서울 한 지점 데이터만으로는 도시 열섬효과와 분리해
  단정할 수 없으며, 추세가 이어진다면 앞으로도 완만하게 상승할 수 있다.

**인사이트 2 (계절)**
- 관찰: 여름은 2016~2023년 평평하다가 2024·2025년 급등(25.15℃, 26.08℃)했고, 겨울은
  변동폭이 크지만(-3.79~+0.11℃) 2025년을 기점으로 하락(2024=-0.34℃→2025=-1.95℃)했다.
- 해석: 여름은 최근 들어 뚜렷하게 더워지는 흐름이 보이는 반면, 겨울은 변동폭이 커서
  앞으로 상승할지 하락할지 방향을 확실하게 장담할 수 없다.

**인사이트 3 (폭염)**
- 관찰: 2018·2025년도가 다른 연도보다 급격히 상승했고(18일, 22일), 2022~2024년도 점진적으로
  증가(2→4→5일)했다.
- 해석: 다만 폭염일수는 원래 해마다 변동이 커서(2016~2021년 1~8일로 들쭉날쭉), 2025년
  한 해의 급등만으로 내년에도 늘어날 것이라 단정하기는 어렵다.

## 6. 결론 및 한계점

### 결론
- 10년간 서울 기온은 완만하지만
  뚜렷하게 상승했고, 특히 여름과 폭염일 증가가 두드러진다. 겨울 기온은 25년을 기점으로 하락하고 있지만, 10년치 연 단위 표본이기에, 통계가 흔들리기 쉽다는 결론을 내릴수있다.

### 한계점
- 서울 단일 지점 데이터라 지구 온난화와 도시 열섬효과를 분리할 수 없다.
- 10년치·연 단위 10개 표본이라 특정 해의 극단값에 통계가 흔들리기 쉽다(끝점 비교 vs
  구간 평균 비교에서 3배 차이가 난 사례로 확인함).
- Open-Meteo 재분석 자료는 실제 관측값과 미세한 차이가 있을 수 있다.

## 7. AI 사용 로그

| 사용 작업 | 사용 이유 | 검증 방법 |
|---|---|---|
| 분석 코드(analysis.py) 구조 설계 및 초안 제시 | 시계열 분석 기법(이동평균, 계절 재분류 등)을 처음 다뤄봐서 방법을 몰랐음 | 본인이 직접 타이핑·실행해 출력값을 확인, 코드의 각 줄 역할을 설명받고 이해 |
| 겨울 계절 재분류 로직(12월→다음 해) 설계 | 연도를 걸치는 겨울을 어떻게 묶을지 판단이 필요했음 | 실제 데이터로 각 winter_year의 포함 월을 직접 확인(코드 실행)해 로직이 의도대로 동작하는지 검증 |
| 인사이트 초안에 대한 사실관계 검토 | 그래프 해석 시 관찰과 해석을 구분하는 게 처음이라 오류 여부를 스스로 판단하기 어려웠음 | AI가 지적한 오류(겨울 온도 방향, 온난화 인과 단정 등)를 실제 수치와 직접 대조해 확인 후 수정 |
| 폭염일수 증가의 극단치 영향 여부 검증 | "+3.3일 증가"가 특정 두 해 때문인지 판단이 어려웠음 | 평균과 중앙값을 각각 계산해 방향이 일치하는지 직접 실행·비교 |
